Enables the clock for the SYSCFG peripheral. 

Enables the SYSCFG peripheral by setting the corresponding bit in the RCC APB2 Peripheral Clock Enable Register (APB2\+ENR). The SYSCFG clock must be enabled before accessing its registers, such as the EXTI configuration registers (EXTICR).

\begin{DoxyNote}{Note}
This function is typically called before configuring GPIO interrupt mappings using the SYSCFG peripheral. 
\end{DoxyNote}
