This repository contains bare-\/metal peripheral drivers for the STM32\+F756\+ZG, implemented using direct register-\/level programming without STM32 HAL or middleware.

The focus of this project is to understand how peripherals work at the hardware level by using the reference manual and building drivers from scratch.
